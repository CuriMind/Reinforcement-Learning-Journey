## 14. 第二波修正：序列级、价值基线与难度感知

> **本章回答的问题**：第 13 章的四个补丁都在改"归一化与采样"，为什么还不够？token 级重要性比在 MoE 上为什么会炸？"把 critic 加回来"是退步还是必要？裁剪的对象到底是权重还是梯度？

> **证据强度**：📙 单篇报告 —— 本章四个方法全部来自 2025–2026 的单篇工作，**无独立复现**。本章最强：GSPO 对"token 级比值方差"的诊断为可验证的机制分析（📗）；本章最弱：**CoDaPO 的具体形式本轮未核实**，本章只给"它要解决什么问题"，不给公式。

> **本章边界**：本章写序列级重要性比（GSPO）、价值基线回归（VAPO）、裁剪结构改造（CISPO）、优势重标定（CoDaPO）四个方向。**不写**第 13 章已讲的归一化补丁；**不写**多轮场景（→第 17 章）；**不写**架构改造（→第 24 章）。

### 14.1 问题：token 级重要性比在 MoE 上会炸

> **本节回答的问题**：同一个序列内，为什么各 token 的概率比会彼此差异极大？

标准 PPO 系实现用的是**逐 token 的概率比**：

$$
r_{i,t}(\theta)=\frac{\pi_\theta(y_{i,t}\mid x,y_{i,<t})}{\pi_{\theta_{\text{old}}}(y_{i,t}\mid x,y_{i,<t})}
$$

**逐项读**：① 分子是新策略在**同一个前缀**下给出这个 token 的概率；② 分母是旧策略的；③ 下标 $t$ 说明**每个 token 各有自己的比值**——这是关键：一个序列会产生 $|y_i|$ 个不同的 $r$。

对稠密模型，这组 $r_{i,t}$ 围绕 1 波动有限；但 **MoE 模型**里，路由（routing）会随参数更新跳变：同一前缀下，新策略可能把 token 分给不同专家，导致**个别 token 的比值偏离到 3–10 倍**，而其它 token 仍在 1 附近。

后果有三层：

| 层次 | 表现 |
|---|---|
| 数值 | clip 把极端 $r$ 截断，但**优势仍乘在上面的 token 上** |
| 优化 | 少数 token 主导梯度 → 训练不稳定、loss 尖峰 |
| 分布 | 这些 token 恰好是"新策略想探索"的位置 → 熵被压制 |

**这不是超参问题，是"用逐 token 比值做重要性纠正"这个结构的问题。**

> **工程提示**：如果你的训练曲线在 MoE 上出现周期性尖峰、且尖峰前熵有小幅跳动，先怀疑 token 级比值，而不是先调 lr。

**小结**：token 级比值在稠密模型上无害，在 MoE 上会因路由跳变产生重尾分布，进而破坏稳定性。下一节看"把比值抬到序列级"为什么能治它。

### 14.2 GSPO：把重要性比抬到序列级

> **本节回答的问题**：如果整个序列只用一个比值，会损失什么、换来什么？

GSPO（📙）定义一个**序列级、长度归一化**的重要性比：

$$
s_i(\theta)=\left(\frac{\pi_\theta(y_i\mid x)}{\pi_{\theta_{\text{old}}}(y_i\mid x)}\right)^{1/|y_i|},
\qquad
\mathcal L=-\mathbb E\left[\min\left(s_i(\theta)\hat A_i,\ \mathrm{clip}\left(s_i(\theta),1-\epsilon,1+\epsilon\right)\hat A_i\right)\right]
$$

**逐项读**：① 分子是整个序列的联合概率（各 token 概率之积）；② **取 $1/|y_i|$ 次幂 = 几何平均**，把它拉回到"平均每个 token 的比值"量级，否则长序列的联合比值会指数偏离；③ clip 作用在**一个标量** $s_i$ 上，而不是 $|y_i|$ 个标量上——这是全部差别。

**这个改动做了什么**：

| 维度 | token 级（PPO/GRPO 原始） | 序列级（GSPO） |
|---|---|---|
| 比值粒度 | 每 token 一个 | 每序列一个 |
| 重尾来源 | MoE 路由跳变 → 个别 token 极端 | 被几何平均抹平 |
| 信用分配 | 细（每 token 各自加权） | 粗（同序列同权重） |
| 方差 | 高（$|y_i|$ 个比值各自估计） | 低（一个标量） |
| 偏差 | 低 | 略高（把"某 token 概率大降"平均掉了） |
| 训练稳定性 | MoE 上差 | 明显好 |

**代价必须说清**：序列级比值**看不见"某一步突然变差"**。如果模型在序列中段崩坏、但整体几何平均仍接近 1，那么这个崩坏不会被 clip 拦住。这正是"用偏差换稳定"——和 PPO 用悲观下界换实现简单是同一类交易（第 7 章）。

> ⚠️ **常见错误**：以为 GSPO 只是"把 clip 挪个位置"。它同时改了**重要性纠正的数学期望对象**：从"逐 token 的重要性采样"变成"整条序列的似然比"。在数学上它优化的是一个**更粗但更稳**的代理目标。

**小结**：GSPO 用"一个序列一个比值 + 几何平均归一化"换掉了 token 级的重尾，代价是丢失序列内的细粒度信用。它在 MoE 上是稳定性刚需，在稠密小模型上收益有限。

### 14.3 VAPO：为什么要"把 critic 加回来"

> **本节回答的问题**：第 12 章说去 critic 是取舍，那什么信号说明"该加回来了"？

VAPO（📙）的核心主张是：**在长 CoT、稀疏奖励的设定下，组内基线不够用**。它的实现由四个部件组成（本节只讲最关键的三个）：

| 部件 | 解决什么 | 与 GRPO 的差别 |
|---|---|---|
| **价值模型预训练** | critic 从零训太慢、太噪 | 用 SFT/回归先给 critic 一个好起点 |
| **解耦 GAE** | critic 训练与策略更新对 $\lambda$ 的需求不同 | 用 $\lambda_{\text{critic}}$ 与 $\lambda_{\text{policy}}$ 两组 |
| **长度自适应 GAE** | 长序列末端 TD 误差累积 | 让 $\lambda$ 随长度/位置调整 |
| **正样本 LM 损失** | 只在成功轨迹上加语言建模损失 | GRPO 没有这一项 |

**解耦 GAE 值得单独写一个式子**，因为它是"一个超参干两件事"的典型修正：

$$
\delta_t=r_t+\gamma V_\psi(s_{t+1})-V_\psi(s_t),\qquad
\hat A_t=\sum_{l\ge0}(\gamma\lambda_{\text{policy}})^l\delta_t^{(l)},\qquad
\mathcal L_V=\sum_t\left(\sum_{l\ge0}(\gamma\lambda_{\text{critic}})^l r_{t+l}-V_\psi(s_t)\right)^2
$$

**逐项读**：① 同一个 TD 误差 $\delta_t$ 同时用于两处；② 策略侧用 $\lambda_{\text{policy}}$（偏小 → 低方差、高偏差）；③ critic 侧用 $\lambda_{\text{critic}}$（通常更大 → 更接近 Monte Carlo 回报，训练信号更"真"）。**拆开的理由**：策略需要"稳"的优势估计，critic 需要"准"的回归目标，两者对偏差—方差的要求相反。

**它为什么在长 CoT 上更有效**：输出越长，组内均值的标准误（12.2 节）相对越不可靠（因为 $\sigma_R$ 随长度增大），而价值网络是**逐 token 的、跨样本共享**的，反而在长序列上有优势。

> **工程提示**：判断是否该上价值基线，看两个量——**平均输出长度**与**组内奖励方差**。若长度 > 2k token 且组内方差长期偏高，组内基线的噪声会吃掉收益，此时价值基线值得试；若长度 < 500，critic 的显存代价通常不值。

**小结**：VAPO 不是"退回 PPO"，而是把 GRPO 丢掉的那部分信号（逐 token 基线）用工程手段补回来，代价是显存。它与 GSPO 解决的是不同问题：GSPO 治**方差结构**，VAPO 治**基线精度**。

### 14.4 CISPO：裁剪权重，而不是裁剪梯度

> **本节回答的问题**：PPO 的 clip 会把超界样本的梯度直接置零，有没有更温和的替代？

标准 clip 目标（第 7 章）在 $r$ 超出区间后**梯度为 0**——样本被"丢弃"。CISPO（📙）的做法是：**保留梯度方向，只裁剪权重本身**，并且对权重做 stop-gradient：

$$
\mathcal L_{\text{CISPO}}=-\mathbb E\left[\mathrm{sg}\left(\hat r_{i,t}\right)\cdot\hat A_{i,t}\cdot\log\pi_\theta(y_{i,t}\mid\cdot)\right],
\qquad
\hat r_{i,t}=\mathrm{clip}\left(r_{i,t},\,1-\epsilon_{\text{low}},\,1+\epsilon_{\text{high}}\right)
$$

**逐项读**：① $\mathrm{sg}(\cdot)$ 表示 stop-gradient——**把裁剪后的权重当常数**，不对它求导；② 于是整个损失退化成"带权重的策略梯度"（REINFORCE 形式），而不是"比值的比值的梯度"；③ $\epsilon_{\text{low}}\neq\epsilon_{\text{high}}$ 允许非对称，与 DAPO 的 Clip-Higher 同向（第 13 章）。

**它与 Clip-Higher 的区别**（两者常被混淆）：

| 方法 | 改的是什么 | 超界样本的命运 |
|---|---|---|
| Clip-Higher（DAPO） | **区间**（放宽上界） | 仍被置零，只是范围更大 |
| Token 级 loss（DAPO） | **归一化方式** | 不变 |
| **CISPO** | **结构**（权重与梯度解耦） | **不再被丢弃**，只是权重被封顶 |

这个区别的后果很实际：在熵濒临崩塌时，Clip-Higher 只能"少杀一些"，CISPO 则"一个都不杀，但压低它们的嗓门"。

> ⚠️ **常见错误**：把 CISPO 当成"PPO 的数值稳定技巧"。它改的是**目标函数的形式**（从 ratio 的梯度变成 log-prob 的梯度），会改变有效学习率与收敛点，不是等价变形。

**小结**：CISPO 的洞察是"限权不限制方向"——保留所有样本的梯度，只用裁剪后的常数权重控制幅度。它治的是 clip 导致的"梯度真空"，与第 13 章的熵崩塌同源。

### 14.5 CoDaPO：用置信度与难度重标定优势

> **本节回答的问题**：如果优势和"模型有多确定""题目有多难"无关，会浪费什么？

**先说清楚本章的立场**：CoDaPO 是本轮**未能独立核实**的条目（📙→❓）。所以本节只写**它要解决的问题**与**这类方法的通用形式**，不给它的具体公式——这正是 `_STYLE-GUIDE.md` 第六节那条硬规则：未核实的条目不得作为骨架。

**要解决的问题**（这个问题本身是明确的、可独立论证的）：

标准 GRPO 的优势（12.2 节）只看"组内相对好坏"，不看两个已知信号：

1. **置信度**：模型对这条回答的把握（可用平均 token 概率、或多次采样的自一致性估计）；
2. **难度**：题目在该模型当前能力下的通过率。

两者的联合分布决定了"这条样本值不值得学"：

| 置信度 | 难度 | 含义 | 该给的权重 |
|:--:|:--:|---|---|
| 低 | 高 | 蒙对了（可能是噪声或侥幸） | 低（别强化运气） |
| 高 | 高 | 真突破 | **高** |
| 低 | 低 | 还没学会基础 | 中（需要，但别过度惩罚） |
| 高 | 低 | 已掌握 | 低（学了也没增量） |

**通用形式**（不是任何单篇的公式，而是这一类方法的骨架）：

$$
A'_{i}=w(\underbrace{c_i}_{\text{置信度}},\ \underbrace{d_x}_{\text{难度}})\cdot A_i,\qquad w>0\ \text{单调递增于 } c_i,\ \text{在 } d_x \text{ 的中间区间取最大}
$$

**逐项读**：① 权重要么放大、要么缩小标准优势，**不改变符号**（这一点很重要：改符号会破坏"优势=方向"的语义）；② 对难度不单调——太简单与太难都降权，这正是"课程学习"的连续版本；③ 权重必须可微或至少可估，否则无法进梯度。

> **工程提示**：即使你不用 CoDaPO，也可以把这张 2×2 表当成**数据筛选器**：把"低置信 × 高难度 = 蒙对"的样本从 RL 数据里剔掉。仅这一步在不改算法的前提下就能减少 reward hacking 的一个来源。

**小结**：这一类方法的共同动机是"优势应当反映样本的信息量，而不只是相对排名"。它的实现细节各家不同且大多未复现，所以本章只确认问题、不背书公式。

### 14.6 四个方向的分工：一张决策表

> **本节回答的问题**：四个方向都能"提稳定性"，我该先上哪个？

| 症状 | 首选 | 次选 | 不选的理由 |
|---|---|---|---|
| MoE，曲线周期性尖峰 | **GSPO**（序列级比值） | CISPO | 加 critic 不解决路由跳变 |
| 长 CoT（>2k）、奖励稀疏 | **VAPO**（价值基线） | GSPO | 组内基线标准误太大 |
| 熵已接近崩塌、clip 丢弃样本多 | **CISPO**（限权不限向） | Clip-Higher | 扩区间只是"少杀" |
| 大量"蒙对"样本污染训练 | 数据筛选 / CoDaPO 类重标定 | 提高难度门槛 | 调 clip 无效 |
| 稠密小模型、短输出 | **什么都不上**（GRPO 足够） | — | 引入复杂度无收益 |

**四者可以叠加，但要按顺序、一次一个**（第 13 章同一条纪律）。

**回填你的账本表**（第 0 章 0.2 节 · L2 行的"标准修法"列）：

```
L2: token 级 loss ✓、序列级 IS ✓（本章）、限权不限制 ✓、价值基线 ✓
   → 待补：架构底座（24 章）、长程稳定性（25 章）
```
