### 15.1 三种解释，与它们各自的可检验预测

> **本节回答的问题**：面对"RL 后分数上升"，有哪几种互斥解释？

同一组观测（pass@1 上升、平均长度上升、pass@k 可能下降）可以被三种机制解释，**它们不是同义词**：

| 解释 | 机制 | 可检验预测 |
|---|---|---|
| **A. 能力提升** | 模型掌握了新的解题路径 | pass@**k 同时上升**；固定长度下仍上升；训练分布外也提升 |
| **B. 分布锐化** | 已有的正确路径被推到高概率区，错误路径被压低 | pass@1 升、**pass@k 降或不升**；熵下降；有效独立样本数下降 |
| **C. 长度补偿** | 输出更长 → 更多中间采样 → 更容易碰对 | **控制长度后增益消失**；同 token 预算下与 base 持平 |

**把三种解释写成一个可分解的式子**：

$$
\Delta_{\text{总}}\approx\underbrace{\Delta_{\text{长度}}}_{\text{C2 可测}}+\underbrace{\Delta_{\text{锐化}}}_{\rho\text{ 可测}}+\underbrace{\Delta_{\text{能力}}}_{\text{残差}}
$$

**逐项读**：① $\Delta_{\text{长度}}$ 是"同样能力下仅因更长而多得的分数"，由 C2（同 token 预算）估计；② $\Delta_{\text{锐化}}$ 是分布变尖带来的 pass@1 提升，由 $\rho$ 的下降幅度估计；③ $\Delta_{\text{能力}}$ 是扣掉前两项后的**残差**——它只能被"剩下"定义，不能被直接测量。这个式子的价值不在算准，而在**强迫你把三项都报出来**。

**关键**：三者可以同时成立，比例不同。所以正确的问题不是"是 A 还是 B"，而是"**A 占多少**"。

**这就是为什么需要一个能把它们分开的量**——下一节的 pass@k 估计式与 15.3 的有效样本数，就是干这个的。

> **工程提示**：任何"RL 提升了推理"的声明，必须同时给三组数：pass@1、pass@k（$k$ 明确）、平均长度。**只给 pass@1 的报告无法评估。**

**小结**：三种解释有各自不同的可检验预测，混在一起谈就变成了立场之争。下一节先把 pass@k 这件"仪器"校准。

### 15.2 pass@k 的正确算法与它的方差

> **本节回答的问题**：pass@k 怎么算才无偏？为什么 $n$ 不够时它毫无意义？

对单个题目采 $n$ 条、其中 $c$ 条正确，则**无偏估计**为（$n\ge k$）：

$$
\widehat{\text{pass@}k}=1-\frac{\binom{n-c}{k}}{\binom{n}{k}}
$$

**逐项读**：① $\binom{n}{k}$ 是从 $n$ 条里取 $k$ 条的所有方式数；② $\binom{n-c}{k}$ 是"取到的 $k$ 条**全错**"的方式数；③ 两者之比 = "随机取 $k$ 条全错"的概率，取补即"至少一条对"。

**为什么不能用 $1-(1-\hat p)^k$**（其中 $\hat p=c/n$）：那是在假设 $\hat p$ 就是真值时做的插值，**它系统性地低估**（因为 $\hat p$ 本身有噪声，$k$ 大时误差被放大）。上式的组合数形式才是无偏的。

**朴素估计为什么有偏**：直接用单条成功率 $\hat p=c/n$ 代入独立假设会得到

$$
\widehat{\text{pass@}k}_{\text{朴素}}=1-\left(1-\hat p\right)^{k}
$$

**逐项读**：① 它把 $\hat p$ 当**真值**；② 但 $\hat p$ 本身是 $n$ 个样本的估计，误差约 $\sqrt{p(1-p)/n}$；③ 取 $k$ 次幂会把误差**放大**，于是 $k$ 越大、$n$ 越小，偏差越严重。这是必须用组合数形式的直接原因。

**$n$ 与 $k$ 的关系是硬约束**：

| $n$ | 能可靠报的最大 $k$ | 说明 |
|---|---|---|
| 8 | 4（勉强） | $k=8$ 时估计退化为"是否全对之一" |
| 32 | 8–16 | 常用配置 |
| 128 | 32 | 报 $k=32$ 的最低要求 |

**方差直觉**：$k$ 越大、$n/k$ 越接近 1，估计的方差越大。报 $k=32$ 却只采了 $n=32$，等于在报"至少一条对"的 0/1 指标。

> ⚠️ **常见错误**：拿不同 $n$ 的 pass@k 直接比较。$n$ 不同，估计的偏差与方差都不同。**报 pass@k 必须同时报 $n$ 与温度 $T$**。

**小结**：pass@k 是一个组合估计量，$n$ 是它的分辨率上限。不带 $(n,T)$ 的 pass@k 数字不可比较。下一节用它来构造"能力 vs 锐化"的判据。

### 15.3 把"锐化"写成可算的量：有效独立样本数

> **本节回答的问题**：怎么把"分布变尖"从一个形容词变成一个数？

如果一条题目的 $n$ 条采样**彼此独立**，那么 pass@k 与 pass@1 满足 $1-(1-p)^k$。但 RL 会把策略推向少数高概率路径，于是**采样之间高度相关**——这等价于"独立试验数变少"。

引入**有效独立样本数** $\rho\in(0,1]$，把预测式改成：

$$
\mathbb E[\text{pass@}k]\approx 1-\left(1-p\right)^{k\rho}
$$

**逐项读**：① $p$ 是单条成功率（pass@1）；② $\rho$ 是"这条题目的采样有多独立"——$\rho=1$ 表示完全独立，$\rho\to0$ 表示 $n$ 条几乎完全一样；③ 用观测到的 pass@k 反解 $\rho$，就得到一个**可比较的锐化指标**（不是定理，是建模假设 📓）。

**用法**：对 base 与 RL 后模型分别估 $(p,\rho)$：

| 情形 | $p$ | $\rho$ | 解读 |
|---|:--:|:--:|---|
| 能力提升 | ↑ | 不变 | 真的学会了新路径 |
| 单纯锐化 | ↑ | ↓ | 把已有路径推到前面，探索变少 |
| 长度补偿 | ↑ | — | 需 15.4 的长度控制才看得出 |

**必须声明的局限**：$\rho$ 是从 pass@k 曲线反解的，它与 $k$ 的取值范围强相关；不同工作用不同 $k$ 会得到不同 $\rho$。所以它适合**同一实验内部的对照**，不适合跨论文比较。

> **工程提示**：把 $\rho$ 加进训练监控（每 200 步在固定 eval 集上估一次）。$\rho$ 持续下降而 $p$ 上升，是"正在用多样性换分数"的早期信号——这比等到 pass@k 掉下来早得多。

**小结**：$\rho$ 提供了一个把"锐化"量化的近似工具，代价是它依赖建模假设。它的正确用法是**同一实验内的相对比较**，不是绝对判据。下一节处理最容易被忽略的混淆变量：长度。

### 15.4 长度控制：三种做法与各自的代价

> **本节回答的问题**：RL 后准确率提升，怎么排除"只是说得更长"？

三种做法，可信度递增、成本也递增：

**做法一：分层比较（最便宜）**

按输出长度分桶（如 0–256、256–512、512–1k、1k+），在**每个桶内**比较 base 与 RL 的准确率。

- 优点：只需已有的采样数据；
- 缺点：**分层本身有选择偏差**——RL 模型在某些桶里的样本可能极少（它已经不产短回答了），此时桶内比较退化为小样本。

**做法二：长度匹配（较可靠）**

对每个题目，从 base 的采样里挑出与 RL 模型**长度分布匹配**的子集（用重采样或倾向得分匹配），再比较。

- 优点：直接消除长度的一阶效应；
- 缺点：会丢掉大量样本，方差上升；匹配变量选错（如只匹配 token 数、不匹配步骤数）仍会残留混淆。

**做法三：同 token 预算（最严格）**

给 base 与 RL **相同的总生成 token 预算**（例如都允许生成 32k token），但 base 可以选"少而长"或"多而短"。

$$
\text{预算}=\underbrace{n}_{\text{采样数}}\times\underbrace{\bar L}_{\text{平均长度}}\quad\Longrightarrow\quad \text{base 用 } n\uparrow,\ \bar L\downarrow;\quad \text{RL 用 } n\downarrow,\ \bar L\uparrow
$$

- 优点：这是**唯一能回答"同样算力下谁更强"**的对照；
- 缺点：需要重新跑一遍 base 的采样，成本最高。

| 做法 | 消除什么 | 残留混淆 | 成本 |
|---|---|---|---|
| 分层 | 长度的一阶效应 | 分层内的选择偏差 | 低 |
| 长度匹配 | 长度分布差异 | 未匹配的变量（步骤数、格式） | 中 |
| 同 token 预算 | 长度与采样数的权衡 | 无（但定义了"更强"的口径） | 高 |

> ⚠️ **常见错误**：只报告"RL 模型在 AIME 上 +8 分"，不报告平均长度变化。如果同时长度从 3k 涨到 12k，那么在同 token 预算下这个增益可能归零甚至为负。

**小结**：长度控制有三个层级，报告时必须说明用了哪一级。**没有长度控制的增益声明，不能称为"能力提升"。**

### 15.5 如何设计一个能证伪的实验

> **本节回答的问题**：我不想站队，我想自己测——最小可执行的实验长什么样？

**四组对照**（缺一组结论就不成立）：

| 组 | 设置 | 用来排除 |
|---|---|---|
| **C1 base** | 原模型，原采样预算 | 基准 |
| **C2 base + 更多 token** | 原模型，采样数 ×4 或长度上限 ×4（同 token 预算） | **长度/采样补偿**（解释 C） |
| **C3 RL** | RL 后模型，原预算 | 待测效应 |
| **C4 RL + 留出集** | RL 模型在**训练中未出现**的题上 | 数据污染 / 记忆化 |

**四条读数**（必须全部报）：

1. `pass@1` 与 `pass@k`（$n\ge 32$，$T$ 固定，**给 $n$ 与 $T$**）；
2. 平均长度与长度分布（不只是均值，要看分位数）；
3. 有效独立样本数 $\rho$（15.3 节）；
4. 分层准确率（至少三个长度桶 + 三个难度桶）。

**判定逻辑**（把 15.1 的三种解释变成可判定的分支）：

```
C3 > C1 且 C3 ≈ C2        → 解释 C（长度/采样补偿）占主导
C3 > C2 且 pass@k 不降    → 支持解释 A（能力提升）
C3 > C2 且 pass@k 下降    → 解释 B（锐化）与 A 混合，需报 ρ
C4 明显低于 C3            → 存在污染或记忆化，本轮结论作废
```

> **工程提示**：把 C2 当成"必须做的对照组"，而不是"可选的严谨性"。它的成本只是多跑一次采样，但它决定了你的结论是"能力"还是"预算"。

**小结**：一个能证伪的实验只需要四组对照与四条读数，成本可控。**关键不是把实验做复杂，而是把对照做全。**

### 15.6 本章的诚实结论

> **本节回答的问题**：那到底答案是什么？

**本章不给答案，给三条状态描述**：

1. **"RL 提升推理能力"目前是 📓 争议**：支持方给出 pass@k 同步上升与分布外迁移的证据；反方给出"同 token 预算下增益消失"与"pass@k 下降"的证据。两方的实验都能复现，**分歧主要来自口径**（用什么预算、什么 $k$、什么难度分层）。
2. **可以确定的是 📗**：RL 会**显著改变输出分布**（长度、熵、自一致性），这部分无需争论；争论在于"分布变化里有多少是能力"。
3. **工程上可操作的是 📗**：不管结论如何，**用 C1–C4 四组对照做决策**都是对的——因为产品要的是"给定预算下的最好结果"，而不是"能力"这个哲学量。
