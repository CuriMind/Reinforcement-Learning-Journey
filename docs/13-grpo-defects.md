## 13. GRPO 的缺陷与第一波修正

> **本章回答的问题**：GRPO 在实际训练里最先坏掉的三个地方是什么？"熵崩塌"为什么比"奖励不涨"更值得先查？DAPO 的四个补丁分别治哪个病？Dr. GRPO 为什么说"除以 std 本身就是个 bug"？

> **证据强度**：📙 单篇报告 —— 本章最强：**熵崩塌先于收益平台期**这一现象在多组实践中被独立观察到（📗）；本章最弱：**四个补丁的增益量级**高度依赖任务（📓），DAPO 报告的数字不能直接外推。

> **本章边界**：本章写长度膨胀、熵崩塌、DAPO 四补丁、Dr. GRPO 的归一化修正、梯度真空。**不写**序列级重要性比与价值基线（→第 14 章）；**不写**长度作为混淆变量的方法论讨论（→第 15 章）；**不写**多轮场景（→第 16–18 章）。

### 13.1 缺陷一：长度膨胀——它既是缺陷，也是混淆变量

> **本节回答的问题**：为什么 RL 训着训着，输出越来越长？这是好事还是坏事？

**现象**：训练中平均输出长度持续上升，同时 pass@1 上升、**pass@k 不一定上升**。

**三个叠加机制**：

| 机制 | 说明 | 是否"真变强" |
|---|---|---|
| **① 长度偏置** | 奖励模型或验证器偏好更长的答案（人类偏好详尽、验证器奖励"步骤多"） | ❌ 灌水 |
| **② 采样效应** | 更长的 CoT = 更多中间采样机会 → 单条更可能碰对 | ❌ 置信度上升，能力未变 |
| **③ 真实收益** | 更长的推理确实解决了更难的问题 | ✅ |

**关键在于三者无法从"长度—准确率"曲线上区分**。这就是第 0 章暗线里说的：**长度是缺陷，也是混淆变量**。本章只处理它作为缺陷的那一面（工程上怎么压住），把它作为混淆变量的那一面交给第 15 章。

**为什么 GRPO 天然倾向变长**（回到 12.3 的目标）：损失按 token 平均，长回答 token 多、总梯度大；而优势又是整条共享的。于是"多说几句、总有机会蒙对"成为一个稳定的局部最优。

> **工程提示**：判断是否发生长度膨胀，不要看绝对长度，看**同一批固定 prompt 上的平均长度**（用固定的 eval set，每 100 步测一次）。绝对值受题目难度分布影响，固定集才可比。

**小结**：长度膨胀有三个来源，只有第三个是真收益。工程上要用"固定 eval 集的长度 + pass@k"两条曲线一起看，才能把它和真实进步区分开。下一节看更致命的那个——熵。

### 13.2 缺陷二：熵崩塌——为什么它比"奖励不涨"更该先查

> **本节回答的问题**：什么叫熵崩塌？为什么它一旦发生就基本无法挽回？

token 级策略熵的常用估计：

$$
\mathcal H(\pi_\theta)=-\frac{1}{\sum_i|y_i|}\sum_{i}\sum_{t}\sum_{a\in\mathcal V}\pi_\theta(a\mid y_{i,<t})\log\pi_\theta(a\mid y_{i,<t})
$$

**逐项读**：① 对每条回答的每个位置求分布熵；② 对词表求和（实际实现多用采样近似，因为 $|\mathcal V|$ 上万）；③ 按 token 总数平均。直观上：**熵 = 模型还有多少种说法**。

**熵崩塌的机制链**（这条链是本章最该记住的）：

```
clip 把"概率比超出区间"的样本梯度置零（第 7 章）
   ↓
被置零的往往是低概率 token（策略还想探索的方向）
   ↓
低概率 token 越来越低 → 分布变尖 → 熵下降
   ↓
熵低 → 组内样本几乎相同 → std(R) → 0 → 优势 → 0
   ↓
【表面现象】奖励曲线走平
   ↓
【误判】"模型到瓶颈了" → 加步数 / 加数据 / 换任务
   ↓
【真相】模型已经没有探索能力，再加算力只是重复采样同一条路径
```

**为什么不可逆**：熵低意味着低概率 token 的概率接近 0；这些 token 在采样中几乎不出现，于是**永远拿不到梯度**。它是一个吸收态。

**判据（按这个顺序查）**：

| 顺序 | 指标 | 健康区间（经验，📓） | 异常含义 |
|:--:|---|---|---|
| 1 | token 级熵 | 缓慢下降，不低于初值的 40% | 骤降 = 即将崩塌 |
| 2 | 组内 std($R$) | 明显 > 0（不是常数） | 接近 0 = 无梯度 |
| 3 | clip_frac | 5%–20% | 长期 <3% = 约束空转；>40% = 步长过大 |
| 4 | 平均长度（固定集） | 平稳或缓升 | 暴涨 = 长度 hack |
| 5 | pass@1 / pass@k | 同时上升 | **只 pass@1 升 = 分布变尖**（第 15 章） |

> ⚠️ **常见错误**：看到奖励曲线走平就加训练步数。**先看熵**。若熵已崩，加步数是纯浪费——这在实践中是最常见的一次性损失几十 GPU·天的错误。

**小结**：熵崩塌是 GRPO 的头号失效模式，因为它是**吸收态**：一旦低概率 token 消失，就没有梯度把它们拉回来。诊断顺序必须是"熵 → 组内 std → clip_frac → 长度 → pass@k"。下一节看补丁怎么针对这条链下手。

### 13.3 DAPO 的四个补丁：每个治一段

> **本节回答的问题**：四个补丁分别对应机制链的哪一环？

DAPO（📙）提出四件事，它们不是并列的优化，而是**针对不同环节**：

**补丁一：Clip-Higher（解耦上下界）**

标准 clip 是对称的 $[1-\epsilon,1+\epsilon]$，但两个方向的作用不对称：上界压"提高概率"的幅度、下界压"降低概率"的幅度。DAPO 改为：

$$
\mathrm{clip}\left(r_t,\ 1-\epsilon_{\text{low}},\ 1+\epsilon_{\text{high}}\right),\qquad \epsilon_{\text{high}}>\epsilon_{\text{low}}\ (\text{如 }0.28\ \text{vs}\ 0.2)
$$

**逐项读**：放宽**上界**（$\epsilon_{\text{high}}$ 更大）意味着"允许把好 token 的概率提得更高"，从而**保住探索**；收紧下界意味着"压坏 token 时更保守"。直觉：熵崩塌发生在"低概率 token 被过度压制"，所以要让**提升**比**压制**更容易发生。

**补丁二：动态采样（Dynamic Sampling）**

过滤掉"全对"与"全错"的组：它们 $\mathrm{std}(\mathbf R)=0$、优势为 0，**零梯度**（12.5 节最后一条）。做法是持续采样直到组内既有对的也有错的，凑够一个 batch。

**补丁三：Token 级损失（Token-Level Loss）**

把损失的归一化从"按回答长度平均后再按组平均"改成**"按 batch 内所有 token 总数平均"**：

$$
\mathcal L_{\text{token}}=\frac{1}{\sum_i|y_i|}\sum_{i}\sum_{t}(\cdot)\quad\text{vs}\quad \mathcal L_{\text{seq}}=\frac{1}{n}\sum_i\frac{1}{|y_i|}\sum_t(\cdot)
$$

**逐项读**：序列级归一化下，**长回答的每个 token 权重被稀释**（因为先除以自己的长度、再除以 $n$），于是长回答的贡献被系统性压低；token 级归一化让每个 token 等权，**长短回答的梯度失衡被修正**。

**补丁四：超长奖励塑形（Overlong Shaping）**

对超过长度上限的回答做软惩罚（而不是直接丢弃），避免"接近上限的回答"获得无意义的优势跳变。

| 补丁 | 治哪一环 | 主要超参 | 风险 |
|---|---|---|---|
| Clip-Higher | 熵崩塌 | $\epsilon_{\text{high}},\epsilon_{\text{low}}$ | 太大 → 训练不稳 |
| 动态采样 | 零梯度组 | 采样上限 | 采样成本上升 |
| Token 级 loss | 长短失衡 | —（结构改动） | 与实现细节强耦合 |
| 超长塑形 | 长度截断跳变 | 上限与惩罚斜率 | 惩罚过重 → 抑制长推理 |

> **工程提示**：四个补丁**不要同时上**。按"熵是否崩 → 是否有零梯度组 → 长短是否失衡"的顺序逐个开，每次只改一个，否则你无法归因。

**小结**：DAPO 的四个补丁不是"更好的算法"，而是**四段独立的止血**。它们全部针对第 13.2 节那条链上的具体环。下一节看另一条思路：也许问题出在"除以 std"本身。

### 13.4 Dr. GRPO：把"除以 std"当成 bug 来修

> **本节回答的问题**：标准化优势看起来天经地义，为什么它本身会引入偏置？

回到 GRPO 的优势定义（12.2 节）：

$$
A_i=\frac{R_i-\mathrm{mean}(\mathbf R)}{\mathrm{std}(\mathbf R)}
$$

Dr. GRPO（📙）的观察是：**除以 $\mathrm{std}(\mathbf R)$ 会让"难度"进入优势**。

**逐项读这个偏置**：考虑两个 prompt，A 的组内奖励方差大（题目区分度高）、B 的方差小（几乎都做对）。两者经标准化后，**A 的优势被压小、B 的优势被放大**——于是模型在"已经会做的题"上获得更大的学习信号，在"难题"上学得更少。这与"应该把算力投向难题"的直觉相反。

修正极简：**只减均值，不除标准差**。

$$
A_i=R_i-\mathrm{mean}(\mathbf R)
$$

另外两处修正（同一篇工作）：

1. **去掉长度归一化**（与 DAPO 补丁三方向一致，理由不同：作者认为按长度平均会系统性地放大长回答的权重）；
2. **按固定常数的 $\frac{1}{\text{max\_len}}$ 归一化**，而不是按实际长度——让不同长度的回答可比。

| 归一化方式 | 优势定义 | 隐含偏好 | 适用 |
|---|---|---|---|
| GRPO 原始 | $(R-\bar R)/\mathrm{std}$ | 偏好低方差（简单）题 | 需要区分度时反而不利 |
| Dr. GRPO | $R-\bar R$ | 无难度偏置 | 多数场景更稳 |
| 去掉长度归一化 | $\sum_t(\cdot)$ 不除 $|y_i|$ | 偏好长回答 | 与长度惩罚一起用 |

> ⚠️ **常见错误**：把 Dr. GRPO 当成"DAPO 的替代品"。它是**对优势定义的一处修正**，与 DAPO 的四个补丁是正交的，可以叠加。

**小结**：这一节的教训比结论更重要——**归一化不是实现细节，它会把"难度"偷偷塞进优势里**。凡是"为了数值稳定"做的除法，都要问一句"它惩罚了谁"。

### 13.5 梯度真空与长短失衡：一个容易忽略的账

> **本节回答的问题**：为什么"短回答"在 GRPO 里几乎学不到东西？

设组内一条短回答 $|y_i|=50$、一条长回答 $|y_j|=2000$，优势相同 $\hat A$。序列级归一化下，两条回答的总梯度量级：

$$
\left\|\nabla\right\|_i\propto\frac{1}{|y_i|}\sum_{t=1}^{|y_i|}\nabla\ell_t\quad\Rightarrow\quad
\frac{\|\nabla\|_i}{\|\nabla\|_j}\approx\frac{|y_i|^{-1}\cdot|y_i|}{|y_j|^{-1}\cdot|y_j|}=1
$$

**逐项读**：序列级归一化下两者的**平均**梯度被拉平了——但注意，这是"平均"被拉平，**方差没有被拉平**：短回答只有 50 个 token 的采样，长回答有 2000 个。短回答的梯度噪声大得多，**实际有效学习信号更弱**。

这就是"梯度真空"（gradient vacuum）的一种表现：**短回答贡献的梯度被长度归一化抹平，同时它的高方差又让它接近噪声**。后果是模型在"简洁作答"这种能力上几乎得不到正反馈——与长度膨胀互为因果。

**修法**（与 13.3 补丁三一致）：token 级归一化 + 对超长做软惩罚，让"短而正确"能真正获得优势。

**小结**：长度归一化不是中性操作。它同时做了两件事：把平均梯度拉平（好处）、把短回答的信噪比拉低（坏处）。理解这一点，"为什么 DAPO 与 Dr. GRPO 都盯着长度"就不再是巧合。

### 13.6 诊断顺序：把本章变成一张操作卡

> **本节回答的问题**：线上训练坏了，第一件事做什么？

| 顺序 | 看什么 | 症状 | 先试什么 | 不要做什么 |
|:--:|---|---|---|---|
| 1 | token 熵 | 骤降 / 已低于初值 40% | Clip-Higher；降 lr；加熵 bonus | 加训练步数 |
| 2 | 组内 std($R$) | 长期接近 0 | 动态采样；调难度配比 | 调 clip |
| 3 | clip_frac | <3% 或 >40% | 调 $\epsilon$ 或 lr | 换算法 |
| 4 | 固定集平均长度 | 暴涨但 pass@k 不升 | 长度惩罚；查验证器是否偏长 | 只看 pass@1 |
| 5 | pass@1 vs pass@k | 只前者升 | 查是否分布变尖（→15 章） | 宣布"能力提升" |

**回填你的账本表**（第 0 章 0.2 节 · L1/L2 行的"典型失效"列）：

```
L1: 长度偏置 ✓、全组同分无梯度 ✓（动态采样）→ 待补：偏好不可传递（9 章）
L2: 熵崩塌 ✓、长度膨胀 ✓、长短失衡 ✓ → 待补：序列级重要性比（14 章）
```
